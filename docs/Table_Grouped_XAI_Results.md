# 七/十变量表格基线的固定分组归因结果

本项属于第4环节。原1160人、原五折、两规格×三算法的30个既有外折模型，完成60个模型/参考精确Shapley游戏与同一预选50人的1200次LIME式局部回归。原始两原因24月CIF分别解释，没有应用后续十变量RF校准策略、重新训练风险模型或切换默认模型。

一次旧派生CSV解析13列、一次原折JSON解析、30个旧外折包各加载一次；六份已存AD OOF hash及Brier全部通过后才开始归因。历史其他原因OOF hash不存在，未虚称复现；当前两原因输出及原保存/加载证据分别保留。全程21,576次CIF、4,513,488条状态行、1200次局部回归，1072.088秒，进程峰值896,069,632字节，低于事前上限。风险基础/校准/预处理拟合均为0，原298/36账本保持，失败重试0。

## 精确归因与敏感性

两原因Shapley最大重构误差为1.11e-15。七变量分七组；十变量前八组分别取值、双侧海马联合一组；NaN和已学习缺失指示保持。组参考来自对应外折训练人月已存插补中位数或标准化器原值均值，没有用测试人群计算参考。

AD全局平均绝对贡献的前二集合，在三算法、两规格、两参考中均为ADAS13与FAQ；RF首位为FAQ，LR/XGBoost首位为ADAS13。这不意味着个人排序或后续组一致，更不表示个人病因。

## 独立留出忠实度

LIME事前固定64个拟合掩码上限、32个独立未用掩码上限，并按有效组数保留部分联盟。基准、改采样种子及改核宽设置均有47/50独立人员、141/150人员—模型配对具备留出；3人无留出，不换人补齐。均值参考设置50/50人、150/150配对具备留出，但它对应不同参考游戏。

## 完成范围与限制

本固定矩阵已完成并关闭，阴性、不一致及不可估计结果保留，不重开旧图增益比较或原置换/参考替换任务。保持回顾性存储快照政策：MRI后期处理275/276晚于索引、无ICV校正、来源/QC/as-of与独立/临床限制不由本研究补齐。缺失组贡献为0仅表示固定缺失模式的游戏没有改变该组，不能推断模型不使用缺失指示器。替换状态也不是生理可行反事实。
