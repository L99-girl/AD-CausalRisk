# 固定图模型分组归因与敏感性结果

本固定任务对应第4环节FR-15/16，回答原先验图预测归因对已有初始化、训练参考和局部代理设置的敏感性。修复版已完成全部矩阵；这是预测解释研究，严格个人因果、图增益、独立和临床效度仍未建立。

原1160人、五外折、三种子的15个既有prior模型，精确分组Shapley两参考共30组；LIME固定50人、四设置、三种子。原CSV一次13列、原折JSON一次、15模型各加载一次，所有原两原因OOF摘要及Brier先核对通过。实际16059次CIF、3604710状态行、600次局部回归；0风险基础/校准拟合，累计仍298/36。运行1549.4秒、峰值339.5MiB，均在冻结预算内。

两原因Shapley最大重构误差8.88e-16，缺失组为0。精确加和只验证既定替换博弈；不证明参考在生理上可行或解释具有唯一病因含义。

输入操作口径：上述一次指13列CSV解析及原折JSON解析，受控执行器对各自同一缓冲区做hash和解析。执行前/后保护清单核验另各流式读取文件字节以算SHA，不解码临床内容；不能把一次解析说成全阶段只有一次文件物理读取。本阶段CSV及折JSON各为执行缓冲区一次＋保护hash两次，共三次字节读取、一次解析。

## 主要发现与适用范围

AD总体平均绝对贡献在两参考、三个初始化下均以ADAS13、FAQ居前，APOE其后；这是本固定图的预测归因，不能据此认证因果作用或推翻输入增量未确立的旧结果。

AD同参考跨初始化的绝对贡献Spearman中位数为0.950–1.000，首位一致93.18%–96.59%；换参考后中位数为0.820–0.841，首位一致76.04%–78.50%。这些排名均只在1056/1160名至少观测3组的人中定义，另104名保留未定义。种子间符号变化为4377/37046个合格人-组配对（六次比较，非独立样本）；参考间为371/16187（三次比较）。高相关不意味着贡献方向或首位完全不变。

LIME基准拟合R²中位数约0.991，但观测点绝对残差在22/150个人-模型配对中超过0.01。只有固定50人中的3人可提供未见掩码（9个人-模型配对），其中6/9的AD留出RMSE超过0.01；其余47人无可用留出掩码。均值参考可评19人（57配对），其中23/57超过0.01；不同参考的可评分母变化，不能据这些比例选择更优配置或认定其余人通过。变窄核宽虽将观测点超阈值降为0/150，可评留出仍有4/9超阈值，且人群很小；保持事前全部设置，不据结果选择。
