## 2. 图语义与个体化层次

节点顺序完全沿用当前十变量：年龄、教育、MMSE、CDR-SB、全局CDR、ADAS13、FAQ、APOE4计数、左海马、右海马。结局和未来访视不作为输入节点。保留原量纲/单位和回顾性存储快照政策；两侧海马为mm3，不能混入课程normalized值。

将旧`TARGETS`限制到本十变量后，恰有下列11条候选路由：

| 目标节点 | 已有候选来源 | 数量 |
| --- | --- | ---: |
| 左海马 | 年龄、教育、APOE4 | 3 |
| MMSE | 年龄、教育、APOE4、左海马 | 4 |
| CDR-SB | 年龄、教育、APOE4、左海马 | 4 |

这些方向是**预设预测路由**，不是测量时间推导的因果方向，也不是本轮学习/验证的个人因果边。全局CDR、ADAS13、FAQ、右海马没有在旧候选中找到相应当前跨节点路由，因此保留自环与直接读出，不新增生物学箭头。当前先验仅跨连6/10个特征，不能称完整十变量因果链；尤其右海马未与左侧对称构图，必须在解释和结果中披露。

所有人共享候选拓扑、参数和节点身份嵌入；个人化发生在观测值、观测状态、有效边和条件注意力。令`m_ij`为第i人第j项是否在冻结快照中有观测。跨节点边仅在两端均观测时激活，缺失节点仍保留自环和缺失状态，供模型表示缺失信息。这个门控只说明快照观测存在，不认证精确来源日期/QC/as-of。MRI原275/276处理日期晚于索引的限制不变。

不因全部或部分缺失重新筛除成员、重抽折或改标签。未投影、缺失、未知日期与临床不可用仍分别处理，不将训练内插补值当观测值构边。

## 3. 从节点到月危险率的明确计算

1. 在每个训练折的人月上拟合原中位数/标准化政策；保持训练所得参数用于测试折。取标准化观测值`z_ij`和观测状态，节点输入为`[m_ij*z_ij, m_ij]`。缺失的值通道固定0，第二通道保留缺失信息，不把这个0称为观测。节点身份嵌入仍可被直接读出。
2. `h_ij(0)=ReLU([m_ij*z_ij,m_ij] W_in + e_j)`，宽度固定8。两层共享节点间的投影，各层有独立参数，不共享受试者标签。
3. 第l层令`q_ij=h_ij W_l`。对来源s和目标t，分数为`LeakyReLU(a_l^T [q_is || q_it], slope=0.2)`。只在有效入边和自环上按来源s做softmax，禁止边的权重严格为0。
4. `h_it(l+1)=ReLU(sum_s alpha_ist q_is)`。固定两层、单头、无dropout。共享路由仍为候选方向，注意力权重是模型运算权重，不是因果强度或自动忠实归因。
5. 按固定顺序展开10×8状态，连接24个月one-hot，用同一个线性头产生每月0/AD/其他痴呆三个logit并softmax。输入结局不进入图或读出头。
6. 按原事件自由生存概率递推两原因24月CIF，不能将单月`predict_proba`当24月概率，也不能单独sigmoid出两个可能相加大于1的风险。

原生实现必须先与`graph.py`使用同一人工常数核对编码、掩码、每层注意力、状态、月危险率及两原因CIF。需要证明图改变在信息/参数允许时可以到达输出；不能要求任何人/任何参数下改图必然变分数。零读出头就是图变化不影响输出的合法反例。展示图必须来自这次实际使用的路由/权重，不另造解释图。

## 4. 最小三臂设计与可证伪判据

| 方案 | 路由 | 回答的问题 |
| --- | --- | --- |
| `self_only` | 十自环，无跨节点边 | 节点表示、缺失信息及非线性存在时，跨节点传播还有多少增量 |
| `prior` | 十自环+原11候选边 | 本固定方向先验约束传播的效果 |
| `semantic_permutation` | 十自环+将同一11边按固定变量置换改名 | 相同无标签拓扑/边数下，先验的变量语义是否有增量 |

置换列表已写死为`[2,5,7,0,9,4,8,1,3,6]`，来源为固定seed20260926的一次无数据置换，不按结局或结果筛选。它保持无标签拓扑和度序列，**不保持每个具名变量的度数或生物学合理性**；单一置换不能代表所有随机图。所有方案输入相同十变量及观测状态，节点身份和读出顺序不置换。

三臂采用同样的参数张量形状、初始化种子、预处理、优化器和训练步数。自环单来源时attention参数对输出不发挥同样作用，因此只能说名义参数形状一致，不能说有效模型容量完全相等。结果限本机制与本对照，不能推广成知识图优于所有图/算法。

固定三种初始化20260926/20260927/20260928，禁止挑最好种子；每种子、每臂使用原五折，各人每种子恰有一次折外预测。主分析使用三种子两原因CIF的等权均值，并报告三种子各自结果及方向一致性。原五折/成员不变，训练/测试受试者无交集；没有按测试集损失早停、选epoch或调参。

优化规格已写入机器文件：Adam、学习率0.001、weight_decay0.0001、40epoch、人月batch256、梯度范数裁剪1.0、无调参/早停。按外折→种子→方案固定顺序执行；同一折和种子在三臂复用相同初始化及批次顺序。最终全量同样按固定规格训练。40epoch不保证充分优化，须据实报告有限优化规格，不能在看见结果后加轮次或换优化器。

主终点为原训练KM、G下限0.05的24月AD IPCW Brier，全体1160人为分母；其他痴呆事件作为已知非AD，早期删失为零权重。配对比较固定为`prior-self_only`及`prior-semantic_permutation`。两个差值各用固定预测/折/KM下10,000次受试者重抽样的97.5%条件区间（分位数0.0125/0.9875），只控制这两个预设比较的区间族；不修复已多轮开发的选择偏差，也不包含重训、划分、KM估计或来源不确定性。

只有两项区间上限均低于0、且三种子各自两项点差均为负时，才描述为“本固定内部规格支持先验路由增量”；否则按混合/未确立增益收口，不重复画图或换seed。AUC/AP、分箱、两原因概率一致性及缺失亚组结果为说明性评价，不另挑阳性终点；5个竞争事件不足以认证其他痴呆精度。上述判据不授权临床、因果或独立有效性主张，也不自动选默认模型。

## 6. 仍未关闭的科研目标

本机制建立“个人观测→实际路由→消息→危险率→CIF”的可审查计算方向，**当前仅用人工参数验证了计算，不是学习后的预测性能证据**。APOE→海马→认知等方向仍为项目历史假设；未确定可识别的个人干预效应、混杂/祖源/选择处理或反事实识别，严格个体因果目标保持未完成。

时间顺序、图注意力、个体化权重、模型得分和图消融差值都不能直接解释为病因或治疗效应。右海马等四节点缺跨路由、只有横断MRI、后期处理/as-of未知、非独立开发人群和少竞争事件等限制完整保留。第4环节后续解释必须绑定最终实际模型/图，并区分注意力、预测贡献、参照敏感性与因果效果；不把本次机制检查宣称完整因果/解释或Java接通。
