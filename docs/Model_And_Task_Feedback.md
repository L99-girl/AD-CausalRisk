# 模型、接口标识与任务反馈

Python 需求中的失败处理要求：输入被拒绝、服务故障与完成计算应能区分，失败不能补零或伪造结果。本阶段提供可选 `python_service/demo_task_feedback.py`，供维护方的现有 Python 演示页面使用；未更改同学的 Java/前端工程和共同契约。

## 当前模型范围

当前授权研究环境的采用模型已训练、保存并做固定规格复现：451名受试者、9082个人月，六种输入/图结构方案，90项原指标与15项配对比较完全一致。宿主读取受保护的复现元数据后生成摘要，不加载模型或重读临床表；不提供元数据的环境明确显示状态未知。模型在首次合格计算时才加载到进程，“未加载”不表示“未训练”。复现一致性不证明临床准确性、个体因果效应或所有需求均已完成。

六种方案分别是最近值、历史特征、可获得性对照、轨迹与先验图、随机可获得性对照、随机图对照。它们属于同一固定研究规格的比较，不是六代系统或六种独立算法。课程默认8091接口仍用加性合成演示规则，其旧模型名并不表示实际拟合了逻辑回归；见[联调约定](Integration_Contract.md)。

接口、模型、输入数据和工作流各有标识，用于检查调用兼容性、定位来源并重现旧结果。编号不是准确率排序。旧路径、字段及标识保留，用户继续访问现有系统，无需选择或启动多个系统。

## 校验案例与故障

正常示例使用已绑定的合法合成输入并产生预测。四种校验案例故意提供非整数MMSE、未来才可获得的来源、缺失可获得日期或错误输入模式，应拒绝且没有预测。

“校验通过：已按规则拒绝”仅在任务详情同时满足合成外层模式、已知方案、FAILED、无结果、预期错误代码及对应HTTP状态时显示。任意服务503、其他错误、缺少证据或列表摘要都不能判成校验通过；原任务存储状态仍为FAILED，原JSON不改。

页面保留错误代码、HTTP状态、任务标识与原时间，主要信息使用中文方案/目的名称，提供“运行正常示例”。该操作显式创建合法输入的新请求，旧失败记录仍保留；不会改写原输入、舍入27.25或跳过MMSE整数规则。模型与来源技术标识放在可展开说明中。

适配器只在内存转换原页面资源。模板锚点不匹配时拒绝适配，维护方需检查模板；不会静默覆盖其他系统。无新增API、评分公式、训练、重试队列或依赖包。

验证：仓库 `python -m unittest discover -s tests -v`；具体宿主的既有接口、合成四拒绝案例、正常恢复、手机布局及旧任务打开行为还需在宿主运行验收。此文不代替临床验证或Java业务接入验收。
