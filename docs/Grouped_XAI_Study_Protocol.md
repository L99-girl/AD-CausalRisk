# 既有外折模型的分组归因研究执行规格

本研究服务第4环节FR-15/16，回答固定先验图预测归因对已实现训练初始化、参考和局部代理设置的敏感性。采用已交付的同1160人、五外折、三种子的15个固定先验图外折模型；最终全量模型和其他两臂不进入此任务。旧图增益比较和正反序解释保持关闭，不寻找更高性能或更一致的解释。

**修复版已按单次确认完成固定真实矩阵，见[结果与限制](Grouped_XAI_Results.md)。** 首轮失败和类型修复记录见[执行状态](Grouped_XAI_Execution_Status.md)。 已有受控模型、来源日期/QC及个人因果的限制继续保留，不由方法或工程检查补齐。

## 固定范围

| 项目 | 锁定范围 |
| --- | --- |
| 被解释输出 | 原始、未校准的24月AD/其他痴呆两原因CIF，分开报告 |
| 解释分组 | 原九组，双侧海马联合；保持缺失掩码和实际图门控 |
| 参考 | 模型已保存的外折训练人月中位数，以及插补后特征的原量纲均值；不用测试人群统计，不重新拟合预处理 |
| 精确分组Shapley | 全1160人、三种子、两参考；每外折模型/参考最多512子集 |
| LIME | 每个原测试折按固定seed=20261027无放回选10人，共50人；各配置复用同一子集，不能按风险、归因或完整性挑人 |
| LIME设置 | 基准：中位数参考、采样seed=20261027、核宽0.75；另逐项换采样seed=20261028、核宽0.30、均值参考；ridge均为1e-6 |
| LIME邻域 | 最多128个唯一拟合掩码及32个未用于拟合的留出掩码；不足时报告实际数/未定义，不重选人或替换为拟合掩码 |

LIME设置为事前固定的逐项敏感性比较，不估计全部配置交互或选择最优配置。三种训练seed只代表已有三次初始化的敏感性，不能冒充Bootstrap重训、训练样本扰动或独立外部验证。

## 执行前强制核对

同一份读取缓冲区先做原字节校验，再以round_trip精度仅解析13列：受试者标识、观察月、结局类型和十输入。冻结折及原输入指纹必须一致；从同一队列按原折复算已有训练人月输入摘要，仅作身份核对，不拟合模型。模型归档仍使用原严格数值加载器，核对原文件/代码/协议/软件/训练输入/作用域身份。

先核对三种子各自完整AD和其他原因OOF摘要，再核对三种子均值的两个摘要及原IPCW Brier，全部通过后才能计算解释。不能用均值相同掩盖单种子错配，也不能换seed或放宽摘要检查。每折三个模型的已存训练参考也须一致。

## 判据与停止

Shapley每人两原因“参考＋贡献和”最大误差不得超过1e-12，缺失组贡献必须精确为0。报告每组总体/观测者分母与有符号/绝对贡献，不只给排名。

同人配对报告种子/参考敏感性，以及匹配50人上的LIME配置和方法比较：绝对贡献Spearman、首位一致、贡献L1差和两边绝对值均超过1e-6时的符号变化。少于3个观测组、常数排序和首位并列单列分母；首位并列容差1e-12。跨折描述不能当成不同人之间的配对稳定性。

LIME拟合邻域R²、真实观测点残差与留出掩码RMSE/R²分别报告；常数响应R²为空、负R²保留。观测残差/留出RMSE超过0.01（CIF一个百分点）的比例只作事前固定诊断，不据此重选核宽/种子。局部代理截距和残差不同于Shapley的精确加和，不能强行摊平。留出掩码也只是所定义替换博弈中的验证，未证明这些组合具有临床可行性。

任何来源/OOF/模型/分组/缺失错配立即停止。资源超限保留FAILED/INCOMPLETE和已发生操作，不自动重试。全部矩阵完成而解释不稳定或LIME忠实度低，也完成本固定问题并如实收口。

## 一次执行预算及输出

本固定单次执行范围限定为原派生CSV一次13列解析、原折JSON一次解析、15个既有模型各加载一次。最多16,575次CIF调用（15基线＋15,360 Shapley＋1,200批量LIME/留出），最多600次LIME局部替代回归；风险基础/校准拟合均0。两小时父进程超时上限、峰值内存2GiB检查，不读新RDA/其他临床表、不改人群/窗口。

单独记录局部替代回归，不计入原298次风险基础/36次校准拟合。只在新受控目录保存计划、操作账本、状态、聚合结果和说明；不保存个体输入/预测/归因、个人hash、邻域状态或效果。模块本身不写文件，宿主封装负责单次读取与授权检查。源码交付不代表已执行真实研究、已部署或Java已接通。

本轮源码复制隔离检查覆盖方法等价、训练参考、留出掩码与完整内存编排；成本探针使用构造常数参数，不能当作真实研究运行时间或效度证据。全部方法、协议与结果均保持预测解释性质，不认证个人病因或治疗效果。
