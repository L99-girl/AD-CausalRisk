# Python四阶段结果一致性

课程SRS将Python职责限定为四阶段工作流及算法HTTP契约。当前固定`deepagent-v1`/`deepagent-causal-warning-v1`除了校验字段和版本，还将质量决定、图、评分和解释绑定到同一份调用请求。此校验适用于原课程合成规则，不能用于验证其他模型的预测。

## 结果校验

`validate_course_result(result, request, CourseContract())`供课程客户端、报告和批处理共用：

- DATA_FUSION按原索引日、最新非空特征、同日重复/冲突及缺失规则核对摘要和全部质量告警；BLOCKED保持null/UNAVAILABLE和实际执行过的单阶段。
- CAUSAL_GRAPH核对节点/边/路径激活、特征来源日及节点证据角色；模型节点不能改称先验，认知/排序节点不能补造采集日。`activePaths`须与图一致。
- WARNING_MODEL核对固定方法标识、原加性规则的逐项数值及最终分数。左右海马均可用时仍优先左侧；左侧0值可用，只有左侧缺失才回退右侧。
- EXPLANATION除总和重构，还逐项核对贡献与方向，`contributionCount`须匹配。两项相反修改抵消、截断后同分、舍入容差内的改写都不能绕过请求绑定。

原分数和贡献仍分别按原规则保留四位小数；方向使用舍入前贡献的±0.002阈值，风险等级使用舍入前总分的0.34/0.65阈值。显示为0.6500的结果可能仍属于MEDIUM，必须保留服务返回的原等级，不能按显示值重新分档。

校验只验证所提供响应是否满足固定演示规则，不调用工作流、评分工具、网络、研究模型或数据库，也不生成新预测。算术复核不能认证响应来源、实际执行或临床效果。原科学限制必须完整且不重复；当前输出审查拒绝额外限制与未知阶段summary元数据，因为这些位置也能夹带未经支持的临床主张。原先允许这些扩展的语义行为已收紧，冻结Schema未修改。新增文案或元数据须先评审规则和调用方。已知质量告警属于当前固定工作流语义，顺序不影响判断，缺失、额外或重复告警均拒绝。

输出审查还核对每个图节点标签、先验边说明/方向、解释标签、message与interpretation。解释文字使用原未舍入贡献的符号；MMSE/MoCA的零项沿用原非负措辞，MMSE_DELTA零项沿用原“暂未上移”措辞，不用显示值或±0.002方向阈值替代。固定词表审查仅适用原课程规则，不是任意医学文本分类器；合格输出仍须人工复核，永远不能因此取得临床使用资格。

接口字段、版本、原评分公式、正常输出和实际阶段耗时未变。Java仍负责AgentClient和业务保存/权限/审计；不能用本模块替代Java端到端验收。失败时客户端不返回伪成功；POST的不可校验响应保持结果未知，恢复工具只GET，批处理停止并且不保存不可信结果/报告。

## 执行与缓存边界

工作流和RunStore分别取得请求快照，再执行输入校验、摘要绑定及计算；调用方随后修改原字典不能改变本次runId、版本、输入或缓存摘要。返回对象与缓存、默认限制文本分别复制，修改一次结果不能污染后续运行。

评分工具的身份、版本、数据版本和质量标志先核对，再映射四阶段结果；完整结果通过原Schema和上述一致性检查后才能返回或进入易失缓存。工具异常、缺字段、非有限数、错误贡献/分数或错误版本均为安全HTTP500/ASSESSMENT_FAILED，不缓存，也不自动重试。输入已合法时，工具内部抛出的输入型异常同样属于执行失败，不能误报为调用方400。

超出浮点可表示范围的量表/MRI整数和JSON转义中的孤立Unicode代理项属于输入错误，返回HTTP400/VALIDATION_400。合法中文访视编号和demo数据版本仍可用。上述修复没有新增错误DTO、公共操作或模型版本；历史结果仍由Java保存，重启不会从Python恢复。

## 可复现验证

从仓库根目录运行`python -m unittest discover -s tests -v`。`test_course_result_integrity.py`覆盖独立JSON Schema仍合法的篡改、实际临时HTTP客户端/只读核对/批处理、原100份档案、64种缺失组合，以及方向和等级的舍入边界；`test_course_execution_integrity.py`覆盖工具故障、异常输入、实际400/500、无缓存/无自动重试和对象复制。不需要研究数据或现有8091/8084服务。
