## 报告含义

| 项目 | 说明 |
| --- | --- |
| 14个三表字段 | 字段名、中文含义、空值规则、量表单位与范围、特征白名单、单位和日期限制。Agent字段边界来自原字节固定Schema；其他CSV规则对应原解析器。 |
| 认知覆盖 | 各项已观测、缺失和其中零值计数；零值属于已观测。只返回计数及缺失位置，不返回输入测量值。 |
| 索引日状态 | 已观测、缺失、同日歧义或没有访视；最近日有多次访视时不任选一条，不用早期值补齐。 |
| 访视时间 | 原声明日期跨度、同日多访视日期组数；不是病程速度、实时可获得性或预测。 |
| 特征时间 | 索引日及以前、索引日之后、没有索引日无法定位分别计数。较晚null不擦除较早非空观测。 |
| 规则可用来源 | 返回按原规则可用的采集日和全部同日等值候选物理行；同特征存在合格时间段冲突时不声称选出来源。只是输入审查，不代表评分实际执行。 |
| 重复与冲突 | 重复行数是同特征同日同值的额外记录数；冲突日期数按同特征同日不同值计算，null与非空冲突也沿用原规则。索引日后的记录不参与这些输入决策计数。 |
| 解释与定位 | 阻断/告警代码配中文解释、表/字段/起始物理行。每条决策最多展示20处来源，完整来源数与截断标志仍返回；单字段缺失与来源候选受原每档案行数上限约束。 |
| 错误指导 | 原问题列表代码不变，附19类可能问题的中文指导。INVALID整批没有档案质量详情，不把部分合法行当作已导入。指导只覆盖已展示的前200项问题代码，完整问题总数仍看原预检字段。 |

`requestDigest`绑定本次原声明和精确CSV文本，`contractSha256`绑定原课程Schema；它们不是来源认证、业务导入凭证或授权。报告不回传输入别名及原量表/特征值。历史可获得日保持null，可获得性、来源真实性与临床有效性标志为false。既有字段及日期仍来自用户声明，合成编号检查不能独立验证真实性。

课程MMSE/MoCA范围保留小数；CDR-SB为[0,18]，不是Global CDR。MRI的normalized比例不自动转换成mm³。报告不引入新整数/离散门槛或新质量标准；同日同值的预检提示不改变原PASS/WARN/BLOCKED结论。ARCHIVED也不代替业务授权判断。

页面使用原生可键盘操作的details，保留错误摘要焦点和输入链接；宽表在焦点可达的区域内横向滚动，手机页面本身不溢出。编辑清除旧详情，响应绑定不符或服务失败时不保留成功结果。没有保存、导出、预测或确认入库操作。
