```python
# model/frame 由宿主独立核实并交付内存；这里没有文件加载或授权行为。
# frame: 唯一字符串 subject_id，加原规格字段，1..256 行。

```

支持 `seven` 和 `multimodal_values`，拒绝可获得性对照臂。七变量分七组；十变量前八个字段各一组、左右海马联合一组。AD 和其他痴呆的原始24月 CIF 分开解释。本规格明确解释原始模型，不解释后续十变量 RF 校准策略，也不改变当前默认输出。

适配器核对原 `preprocess → hazards` 管道、字段顺序、原训练插补/标准化/月份编码配置，以及三个原因类别。中位数来自已拟合 `SimpleImputer.statistics_`；均值来自插补后已拟合 `StandardScaler.mean_` 的前 n 个原始值位置，不包含其后的缺失指示器均值。两者都来自相应外折训练人月，均不使用待解释人员计算参考。

只替换原本观测到的值，NaN 和已学习的缺失指示器位置保持。支持整数及 nullable 整数输入上的小数参考，使用独立 float64 副本；拒绝布尔、复数、字符串、无穷、不能精确表示为 float64 的整数、重复人员及单侧 MRI 缺失。原管道自己完成插补和变换，不扩充缺失指示列。

因此缺失组归因为0只能说明此条件游戏没有改变该组，不能推断模型不利用缺失。构造检查明确展示：缺失指示器能改变 CIF，而保持该缺失模式的游戏仍给该组0贡献。

## 归因与局部忠实度

精确分组 Shapley 复用完整枚举，最多七组128个、九组512个联盟。两原因各自满足参考 CIF 加贡献和重构观测 CIF。重构成立不证明个人病因、反事实可行性或解释唯一性，也不等于运行外部 SHAP 包。

LIME 式替代模型复用原加权岭回归算子，默认最多64个拟合掩码、32个不参与拟合的留出掩码。先根据相对所选参考的有效组数 k，固定拟合上限：

`min(64, 2**k, max(k+1, 2**k//2))`

这条规则在新真实结果出现前固定，用于避免拟合掩码耗尽全部小型联盟空间。k=0不拟合替代回归；k=1通常仍没有独立留出。没有留出、响应常量导致 R² 未定义时，保留未知和分母；负 R² 不截断。不依据未来结果选择更小核宽或其他“最好”配置，也不声称预留规则已经改善真实忠实度。批量和串行计算使用同一拟合/留出集合。

每次原 CIF 调用核对输入副本与输出人员顺序，两原因数值通过通用算子检查。整次解释前后核对模型的内存状态摘要及选定输入；摘要不是来源认证，也不能发现中途改写后恢复的状态。调用方需保证独占、可信模型对象。失败不返回部分解释，适配器没有自动重试。
