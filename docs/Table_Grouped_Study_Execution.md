# 表格分组归因的编排与执行准入

第4环节的表格基线分组归因编排及单次执行准入已完成构造验收，随后固定真实矩阵也已完成，见[结果与限制](Table_Grouped_XAI_Results.md)。方法依据见[表格分组预测归因](Table_Grouped_Attribution.md)；当前新增的是完整矩阵及执行门槛，不能据构造检查声明实际解释稳定或具有因果意义。

[table_xai_study.py](../research_runtime/table_xai_study.py)只接收调用方已核实的内存队列、原划分、候选身份和旧模型包。它不读取文件、不反序列化、不拟合风险或预处理模型、不授权执行，也不接入 Java/HTTP。受控主机的单次读取封装独立维护；未取得该具体执行范围确认时，封装在读取受控输入或创建真实运行目录前退出。

## 执行前门槛

七变量外折包必须是 `NESTED_OUTER_RESEARCH_VALIDATION`，绑定原训练计划、家族、外折和七字段；十变量必须是 `MULTIMODAL_OUTER_VALIDATION`、`multimodal_values`、原始未校准策略及回顾性标签。核对原管道、保存的参考和实际分类器家族。仅接受两规格×三算法×五折的30个不同模型对象，拒绝最终包、可获得性臂、错折、错家族、错计划及校准输出。已有 final-only loader 保持原逻辑。

身份校验作用于已经反序列化的内存对象。宿主必须先核对独立可信的来源清单及模型原字节 hash，再反序列化相同内存缓冲区；pickle 仍是可执行内容，hash 不能替代来源信任。元数据一致也不认证真实来源或临床用途。

原折文件的人员顺序和位置顺序必须同时匹配，训练/测试互斥且所有人恰好折外一次，不重新划分或更换人员。相同规格/折内，三算法保存的训练参考与缺失指示器布局必须一致。参考来自训练人月，不从测试人群重新计算。

30份原始两原因 CIF 先生成完整 OOF；六份已存 AD OOF hash 和 Brier 全部通过后，才允许第一组归因。历史其他原因 OOF hash 缺失始终明确记录，不能升级为已核验。当前其他原因输出检查有限性、概率边界、两原因和及人员顺序；旧两原因保存/加载证据继续保留。

## 固定矩阵与聚合

矩阵保持60组 Shapley、同一预选50人的1200组 LIME 配置。种子、核宽、两训练参考、缺失策略和64拟合/32留出规则保持此前规格。精确 Shapley 重构及预测绑定必须在 `1e-12` 内；缺失组贡献必须为0。

按两原因、规格、算法、参考报告全体及五折的有符号/绝对贡献、组观测人数。排序敏感性只使用相对所选参考有效的观测组；比较两参考时取有效组交集。少于三组、恒定秩或首位并列按既有聚合规则保留未定义。算法间排序比较不是算法优越性或同算法跨重训证据。

LIME 分别报告拟合邻域和独立留出的 RMSE、MAE、R²、观测点残差及超过0.01 CIF单位的数量。缺失留出、常量响应及负 R² 保留；同一人跨三算法的150个人员—模型配对与50个独立人员分母分别汇总。局部代理与对应精确 Shapley 在同一人员、规格和参考下比较，不把重构要求强加给代理模型。

MAE 通过收集已经求值的邻域状态和两原因预测，再使用原替代模型系数及同一权重计算；没有额外 CIF 或回归。通用 Shapley/LIME 数值核心、CIF、估计器和评价源码均不改变。

## 运行控制与状态

未来固定上限保持一次13列旧派生 CSV、一次原折 JSON、30个旧外折包各加载一次；21,630 CIF、4,576,560状态行、最多1200次局部替代回归、两小时及2 GiB。风险/校准/预处理拟合0，无新临床表或新增人群/窗口。授权只适用于精确绑定的方案和预算，不能套用旧图或 MMSE 的读取确认。

封装使用读取的同一缓冲区做 hash 和解析/加载。原始读取、解析次数与 CIF/回归尝试、完成次数分开记录；完整性核验的字节读取不冒充额外临床解析，也不宣传为零磁盘读取。所有风险/预处理 fit、优化器和未绑定的参数加载被阻断。真实输出只保存聚合、实际计数和源产物身份，不保存人员输入、预测、贡献、掩码或个人 hash。

父进程先以排他文件记录一次启动，再启动工作进程；已有启动或输出目录拒绝重用。父进程检查墙钟和 Windows 工作进程峰值内存，超限或监控失败终止运行，保留 `Parent_Stop.json`，即使子进程尚未创建输出目录也保留记录。该停止记录优先于子进程部分结果；不能把部分聚合或单独 COMPLETE 文件解释成成功。当前监控只验收 Windows，不宣称跨平台。

计算模块复用原 `grouped_xai_study.distribution/paired`、原 CIF 和评价函数。完整编排使用既有22包 CPU 图环境以满足这些聚合模块的导入依赖，不运行图模型或优化器；表格方法适配仍可单独在原表格环境运行。未安装或改变环境。
